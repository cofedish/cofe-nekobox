# Темы и анимации

## Доступные темы
- System — следует системной палитре
- Light — светлая тема
- Dark — тёмная тема
- Lucifer — авторская тёмная палитра
- BAD600 Light — светлая контрастная палитра с лаймовым акцентом
- BAD600 Dark — тёмная контрастная палитра с лаймовым акцентом

## Редизайн главного окна
- Новый UI главного окна (glass/neon, карточки, орб Connect, анимированный фон) применяется ко всем встроенным темам.
- Между темами меняется цветовая палитра, а структура и анимации остаются единообразными.
- Для уменьшения движения используйте Reduce motion (анимации фона и Connect будут отключены).

## Как переключить
- В Settings → Theme
- В нижней части бокового меню (drawer)

## Reduce motion
Опция отключает анимации (волна фона, анимация Connect).
Ищите в Settings → Style.
