# Маршрутизация приложений

## Что это делает

Раздел **Rules -> Open application routing** позволяет направлять трафик приложений:

- `Все через Proxy/TUN`: список не используется.
- `Только выбранные через Proxy/TUN`: указанные приложения идут через прокси, остальные напрямую.
- `Все через Proxy/TUN, кроме выбранных`: указанные приложения идут напрямую, остальные через прокси.

## Как добавить приложение

Нажмите **Add application** и выберите один из способов:

1. `Running`:
- поиск по имени/пути;
- выбрать процесс;
- выбрать способ матчинга: `process_name` или `process_path`;
- нажать **Add**.

2. `Select file`:
- выбрать `.exe`/бинарь;
- при необходимости задать отображаемое имя;
- добавить по имени процесса или по полному пути.

3. `From clipboard`:
- вставить путь из буфера;
- добавить по имени или пути.

## Управление списком

- Поиск по текущему списку.
- Удаление: кнопка **Remove** или клавиша `Del`.
- Контекстное меню: переименовать отображаемое имя, копировать значение, открыть папку (для path-правил), удалить.
- Импорт/экспорт: JSON через кнопки **Import/Export**.

## Ограничения

- Правила по процессам применяются в режиме **TUN**.
- Для `process_path` путь должен быть доступен системе (на некоторых процессах путь может быть недоступен).

## Быстрая проверка (smoke)

1. Включить TUN и выбрать режим `Только выбранные через Proxy/TUN`.
2. Добавить приложение (например браузер).
3. Проверить:
- трафик выбранного приложения идет через прокси;
- остальное приложение/процесс идет напрямую.
4. Переключить на режим `Все через Proxy/TUN, кроме выбранных` и убедиться, что поведение поменялось.

Примеры команд:

- Linux:
`ip a | grep -E "tun|cofebox-tun"`
`curl -s https://ifconfig.me`

- Windows PowerShell:
`curl.exe -s https://ifconfig.me`
`Get-NetAdapter | Where-Object { $_.Name -match "tun|cofebox" }`
