# Hotspot Gateway Mode (MVP)

## Что это
`Hotspot Gateway` поднимает на ПК точку доступа Wi‑Fi и направляет трафик подключённых устройств через CofeBox.

В текущем MVP доступен один режим:
- `Full-tunnel для Hotspot`: весь трафик подсети hotspot идёт через `tun` интерфейс CofeBox.

Трафик самого ПК работает как обычно и не переключается автоматически в hotspot-правила.

## Ограничения MVP
- Нет split routing по доменам для клиентов hotspot.
- Нет per-device политики (только общий full-tunnel).
- IPv6 в hotspot-маршрутизации не настраивается.

## Как включить
1. Включите TUN в CofeBox.
2. Откройте страницу `Правила`.
3. В блоке `Hotspot Gateway (сеть CofeBox)` нажмите `Старт` или включите тумблер.
4. Подключите устройство к Wi‑Fi:
- SSID и пароль показаны в карточке.
- Можно открыть QR кнопкой `Показать QR`.

## Что делает приложение

### Linux
- Поднимает hotspot через NetworkManager (`nmcli`).
- Применяет full-tunnel правила через `cofebox-net-helper` (через `pkexec`):
- mark трафика подсети hotspot
- `ip rule` + таблица маршрутизации `100`
- NAT (`MASQUERADE`) в сторону `tun` интерфейса

### Windows
- Пытается включить hosted network / Mobile Hotspot.
- Настраивает ICS (Internet Connection Sharing) через `cofebox-net-helper` с правами администратора:
- `public` = `tun` интерфейс CofeBox
- `private` = интерфейс hotspot

## Диагностика
Кнопка `Диагностика` проверяет:
- hotspot интерфейс и его IPv4
- состояние `tun` интерфейса
- наличие policy routing/NAT (Linux) или ICS mapping (Windows)
- число обнаруженных клиентов

Если есть ошибка, показывается точная причина и шаг для исправления.

## Типовые проблемы
- `Адаптер Wi-Fi не поддерживает точку доступа`
  - Устройство/драйвер не поддерживает AP/hosted mode.
- `Нужны права администратора для настройки сети`
  - Подтвердите запрос `pkexec`/UAC.
- `Hotspot включен, но интернет не раздаётся: проверьте подключение к туннелю`
  - Включите TUN в CofeBox и проверьте, что `tun` интерфейс поднят.
- `Не найден cofebox-net-helper`
  - Проверьте, что helper входит в сборку/дистрибутив и лежит рядом с основным бинарём.
